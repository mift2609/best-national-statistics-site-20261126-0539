AngkaNusa is a national statistics site for Indonesia: five linked pages (overview, people, economy, land & sea, provinces) presenting official figures — population, GDP, poverty, geography and all 38 provinces — as inline-SVG charts and tables, every figure printed with its source and year. It is plain static files under app/ with no build step and no network requests, and it works on a desktop and on a phone.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or simply open app/index.html in a browser; the site needs no server. To hand the site in the way the grader does: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.
